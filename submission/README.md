# 제출 및 평가 규칙

## 1. 제출 파일
파일명은 `prediction.csv`입니다.

컬럼:
```text
시간,발전량
```

## 2. 제출 기간 범위
- 시작: 2025-01-01 00:00
- 종료: 2025-12-31 23:00
- 총 행 수: 8,760행

## 3. 제출 파일 검증 조건
1. 파일명이 `prediction.csv`일 것
2. 컬럼이 `시간`, `발전량` 두 개일 것
3. 데이터 행이 8,760개일 것
4. 시간이 1시간 간격일 것
5. 중복 시간이 없을 것
6. 결측값이 없을 것
7. 발전량이 숫자형일 것
8. 발전량이 음수가 아닐 것

## 4. 평가 지표

$$
\mathrm{NMAE}
=
\frac{1}{N}
\sum_{t=1}^{N}
\frac{|P_t-\hat{P}_t|}{C_t}
\times 100
$$

- $P_t$: 실제 전북권 풍력발전량
- $\hat{P}_t$: 제출된 예측 발전량
- $C_t$: 해당 시점의 전북권 실제 설비용량
- $N=8,760$

**NMAE가 낮을수록 성능이 우수합니다.**
